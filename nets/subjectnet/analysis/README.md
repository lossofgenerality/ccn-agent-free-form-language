# Looking inside SubjectNet

1. `nets/SubjectNet_as_matrices.nb`: the training written out, and the trained model in `MatrixForm` on "slide it right 2 units".
2. `nets/SubjectNetReport.md`: our own net against Wolfram's, on one job: data, the algorithm, the four tests and the timings.
3. The 3D view (`viz/viewer-data.json`, published as `3d.html`): every weight, the lit columns, ReLU and the softmax, for thirteen sentences.
