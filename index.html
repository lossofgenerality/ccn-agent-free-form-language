CCN Agent Free-Form Language

A plain, spoken-style language for defining CCN's agents, with Wolfram and Python steps where precision is needed, and the agents' own small neural nets, trained outside any conversational-construct.

Working parts

Net diagram editor

Draw a small neural net in the browser: feature groups, a hash, slots, layers, dropout, joins and a softmax. Diagram → Code writes a Wolfram notebook that trains the net in our own code and with NetTrain.

Motion phrases

Reads phrases such as “move along the path while spinning counterclockwise and move upwards”, alone or inside paragraphs, into RotationTransform and TranslationTransform.

Notebook · Tests · Corpus · Report

SubjectNet

The first of the agents' own nets. It decides whether a motion part is about the object or about something else. It comes in two versions, our own code and Wolfram's, which agree on every decision.

The specifications (drafts for comment)

  • Design specification: spoken lines, Wolfram and Python steps, and the uses Claude: ledger
  • Implementation specification: the reader, the compiler and AgentKernel
  • The agents' own neural nets, trained in Wolfram and in Python and exchanged as ONNX
  • Daemons: processes that watch CCN's systems and invoke agents or software

Wolfram code here is delivered as notebooks (.nb). The documents open on GitHub.
